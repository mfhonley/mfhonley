# Жан Бейсикеев — чекпойнты

9 минималистичных слайдов для выступления примерно на 20 минут.
Первые 3 — личный путь, следующие 5 — как прийти к идее, разобраться
в проблеме и проверить решение; последний — вопросы.
На экране только короткие чекпойнты. Содержательные опоры, примеры
и переходы для рассказа своими словами — в `speaker-notes.md` и по клавише N.

Всегда белый фон и тёмный текст, системные шрифты с кириллицей, сцена 1280×720.
На первом слайде только `hello`.
Опыт объединён на одном слайде: «nFactorial (edutech)», «Финтех», «Фильм».
Справа — предоставленный скриншот фильма из `public/assets/film.png`.
Отдельные слайды «5 лет» и «8 класс» удалены.
Слайд со списком проектов удалён. Третий слайд — «Как я пришёл к идее».
Практический блок: поиск идеи → потребность → опыт в сфере → ресерч →
проверка на практике. Подробности — в заметках.
Паттерн оболочки — `focworld/present` и `mindzan/present`.
После загрузки для показа не нужны внешние шрифты, изображения или API.

## Запуск

```bash
cd present
npm ci
npm run dev
```

Открыть http://127.0.0.1:3008/?slide=1. Порт фиксирован.
В этой рабочей копии зависимости уже подключены из `focworld/present`.
На новом компьютере установите их командой `npm ci`.

- Стрелки, Space, Page Up / Page Down — листать; Shift + Space — назад.
- Home / End — первый и последний слайд.
- F — полный экран. В нём управление появляется при наведении вниз или фокусе с клавиатуры.
- G — обзор слайдов, N — «Что рассказать». Горячие клавиши работают и в русской раскладке.
- Escape — закрыть обзор или заметки, выйти из полного экрана.
- Свайп — переключение на телефоне.
- Номер слайда хранится в URL и localStorage.

Заметки открываются на текущем экране. Там же — источники и необязательный
ориентир времени. Для показа аудитории закройте заметки клавишей Escape.
Переключение только вручную; темп выбирает выступающий.

## Сборка и файлы

```bash
npm run build
npm run preview
```

Готовый сайт — `dist/`; production preview — http://127.0.0.1:4178/.
Его можно размещать в подпапке `/present/` благодаря относительным путям ассетов.

- `zhan-beissikeyev.pdf` — 9 страниц 16:9 для показа и отправки.
- `output.pptx` — редактируемый PowerPoint с заметками к каждому слайду.
- `speaker-notes.md` — материал для подготовки: тезисы, примеры и переходы.
- Кнопка PDF открывает печать браузера: выберите «Сохранить как PDF», включите фон.

Автоматический PDF при запущенном сервере:

```bash
npm run export:pdf
```

Для экспорта нужен Playwright и Chromium. В этой рабочей копии используется
установленный Playwright из `mindzan/app`. В независимой копии установите
`npm install --no-save playwright`, затем `npx playwright install chromium`.
`PRESENT_URL` позволяет указать другой адрес сервера, `PLAYWRIGHT_PACKAGE` —
абсолютный путь к `package.json` проекта с установленным Playwright.

## Редактирование

`src/deck.mjs` — тексты, геометрия, источники и тайминг слайдов.
`src/talking-points.mjs` — содержание рассказа; заметки браузера и PowerPoint
используют эти же данные. `npm run export:notes` обновляет `speaker-notes.md`.
`src/main.jsx` — показ и навигация, `src/styles.css` — оболочка,
масштабирование и печать. Презентация независима от главной страницы сайта.

Основные факты: `../llms.txt`, `../README.md`, резюме и
[интервью Digital Business от 21.04.2026](https://digitalbusiness.kz/2026-04-21/shkolnik-iz-pavlodara-v-15-let-uzhe-zarabatival-500-tisyach-tenge-a-v-17-uspeshno-prodal-startap/).
«3 недели» в заметках относится к первоначальной версии MindZan.
Выводы и упражнения для поиска идеи — предлагаемый авторский разбор;
условные примеры не приписываются реальным клиентам MindZan.

Локальный сборщик PowerPoint: `../tmp/slides/zhan-event/build/build.mjs`.
Он использует установленную среду Codex и общие данные из `src/deck.mjs`.
После редактирования заново экспортируйте PDF и PPTX: готовые файлы сами не обновляются.
